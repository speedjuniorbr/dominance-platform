# DOMINANCE Platform — identidade visual (v1.0)

## Arquitetura de marca

Marca-mãe **DOMINANCE® Platform**, com os produtos como complemento de nome. O nome DOMINANCE vem
sempre na frente.

| Marca | Símbolo | Arquivo | Uso |
|---|---|---|---|
| DOMINANCE® Platform | **D completo**: o D com três faixas acesas, laranja, azul e verde | `brand/svg/dominance-platform-mark.svg` | Capa, site, contratos, assinatura institucional |
| DOMINANCE Workspace | **Portal**: D aberto à esquerda com ponto dourado dentro | `brand/svg/dominance-workspace-mark-*.svg` | App do usuário final |
| DOMINANCE Governance | **Camadas**: D em três faixas, só a do meio em ouro | `brand/svg/dominance-governance-mark-*.svg` | Console de governança |
| DOMINANCE Core | **Monólito**: D facetado com fenda dourada | `brand/svg/dominance-core-mark-*.svg` | Hardware: porta do rack, etiquetas, documentação técnica |

Sufixos `-dark` e `-light`: `dark` é o símbolo escuro, para fundo claro; `light` é o símbolo claro, para
fundo escuro.
Nos PNGs de `brand/png/` a convenção é a do fundo: `_dark` é para usar sobre fundo escuro e `_light` sobre
fundo claro.

Frase de assinatura: **Soberania em todas as camadas.**

Cada app de produto mostra o próprio símbolo e a linha "Parte da DOMINANCE® Platform" com o D completo.

## Cores

| Nome | Hex | Uso |
|---|---|---|
| Noite soberana | `#0B1324` | Fundo escuro, texto, chassi |
| Cobalto | `#2342C8` | Ações, links, nuvem |
| Ouro soberano | `#C9962F` | O ponto da marca, processamento local, LED de atividade |
| Ouro para texto | `#8A6417` | Texto dourado sobre fundo claro (contraste) |
| Aço | `#8A94A6` | Texto secundário, gravações |
| Névoa | `#F3F5F9` | Fundo claro |
| Camada Workspace | `#E07B39` | Só para identificar a camada |
| Camada Governance | `#3D5BE0` | Só para identificar a camada |
| Camada Core | `#2E9E6B` | Só para identificar a camada |

O ouro é acento: use pouco. As cores de camada não são cores de interface: aparecem apenas quando a
camada precisa ser identificada (diagramas, etiquetas, faixas do D completo).

## Tipografia

- Marca e títulos: **Archivo** expandido (largura 112 a 125%), peso 700 a 800, espaçamento largo no nome.
- Texto: **IBM Plex Sans**.
- Números, código, chaves e etiquetas de equipamento: **IBM Plex Mono**.
- Em documentos Office, use Arial para garantir a mesma aparência em qualquer computador. As assinaturas
  da marca entram sempre como imagem.

## Regras de uso

- Não recolorir os símbolos fora da paleta. Não aplicar sombra, gradiente ou contorno.
- Área de proteção mínima: a altura da faixa central do símbolo, em volta de toda a assinatura.
- Tamanho mínimo: 16 px para os símbolos; 24 px para o D completo.
- O símbolo do Monólito vai fresado ou gravado no metal do Core; só a fenda dourada acende.
- Equipamentos de terceiros no rack não recebem a marca DOMINANCE; a marca fica no gabinete.

## Pendências

- Versão final dos vetores por um designer, com ajuste óptico.
